# tw-address-normalizer

把台灣地址整理成一致的寫法。純 Python、零依賴。

Normalize Taiwanese postal addresses to one consistent written form. Pure Python, no dependencies.

```python
>>> from tw_address_normalizer import normalize
>>> normalize("台北縣板橋市文化路１段１００巷五弄十三-一號三F")
'新北市板橋區文化路一段100巷5弄13之1號3樓'
```

## 會處理什麼

| 規則 | 例子 |
|---|---|
| 全形轉半形、去空白 | `民族東路１７號` → `民族東路17號` |
| 縣市名用「臺」 | `台北市` → `臺北市` |
| 改制前的縣名 | `臺北縣板橋市` → `新北市板橋區`、`桃園縣中壢市` → `桃園市中壢區` |
| 易混淆字 | `巿`→`市`、`鎭`→`鎮`、`内`→`內` |
| 路段用國字 | `信義路2段` → `信義路二段` |
| 巷、弄、號、樓用數字 | `一百零九巷十一弄三號` → `109巷11弄3號` |
| 連字號改「之」 | `5-1號` → `5之1號`、`3樓-2` → `3樓之2` |
| 樓層 | `10F` → `10樓`、`地下二樓` → `B2`、`B1F` → `B1` |
| 開頭的國名 | `台灣台北市…`、`中華民國臺灣省…` → `臺北市…`（開頭的郵遞區號保留） |

巷、號的數字只在前面是路、街、段、巷時才轉換，所以「五權新一巷」這類名稱不會被改動。看不懂的部分一律原樣保留，結果再跑一次也不會變。

規則依照中華郵政地址的慣用寫法。在約 17 萬筆真實地址上測試過，沒有錯誤，結果穩定。

## 不會處理什麼

- 不驗證地址是否存在，也不查郵遞區號（需要的話可以搭配 [zipcodetw](https://pypi.org/project/zipcodetw/)）
- 不拆欄位（縣市、區、路……）
- 鄉鎮區名稱裡的「台」不改（例如台東縣台東市），因為官方名稱本身寫法不一

## 安裝與使用

```sh
pip install git+https://github.com/eit/tw-address-normalizer
```

```python
from tw_address_normalizer import normalize, to_int, from_int

normalize("臺北市信義路二段213號十二樓之一")  # '臺北市信義路二段213號12樓之1'
to_int("一百零五")   # 105
from_int(12)        # '十二'
```

整批處理，一行一筆：

```sh
python -m tw_address_normalizer < addresses.txt > normalized.txt
```
